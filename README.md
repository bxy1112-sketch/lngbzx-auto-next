# 辽宁干部在线学习网：合规连续学习

适用网站：`https://zyjs.lngbzx.gov.cn/`

## 一键安装

已安装 Tampermonkey：**[点此一键安装脚本](https://raw.githubusercontent.com/bxy1112-sketch/lngbzx-auto-next/main/lngbzx-auto-next.user.js)**

当前版本：`3.0.2`。脚本会记住同一视频真实播放过程中已经到达的时间；即使平台在结束瞬间把播放器重置为 00:00，也会在确认确实播放到结尾后安全推进。真实结束后约在 0.35 秒时执行推进，并在页面确认换节后约 0.1 秒重新检测播放器；服务器加载新视频所需的时间仍由平台决定。

这个 Tampermonkey 脚本从“我的课程 → 未完成课程”手动启动一次，按页面顺序学习已经选好的普通视频课程，并自动处理分页。

它只在视频真实播放到结尾后推进。脚本先给平台自身的结束处理留出时间；平台没有换节时，只会点击页面上唯一、可见且文字严格为“下一节”“下一课”“下一讲”等白名单名称的控件一次。它不点击右侧课程目录，也不会把“按钮缺失”或“课程从列表消失”当作完成，而是回到当前课程 ID 对应的课程详情页。只有详情页恰好存在一个可见进度组件，并且同时明确显示：

- `aria-valuenow="100"`
- 进度条宽度为 `100%`
- 可见进度文字为 `100%`

脚本才会返回“我的课程”并启动下一门。

脚本不会倍速、快进、修改 `currentTime`、伪造观看时长、调用学习进度接口、伪造心跳、答题、自动选课，或绕过登录和服务端校验。它不会点击“我要选课”“取消选课”“课程测验”“考试”“练习”等控件。

## 安装或升级

1. 安装并启用 Tampermonkey。
2. 在 Tampermonkey 管理面板中停用原来的“新版辽宁省干部在线学习网……”等同站点旧脚本，避免多个脚本同时操作。
3. 点击 **[点此一键安装脚本](https://raw.githubusercontent.com/bxy1112-sketch/lngbzx-auto-next/main/lngbzx-auto-next.user.js)**，在 Tampermonkey 安装确认页核对名称和版本后点击“安装”或“更新”。
4. 确认脚本开关为启用，然后刷新学习网站。

脚本内置同一公开地址作为更新源。以后只要发布更高版本，Tampermonkey 会按自身的更新周期检查；也可以在管理面板中手动执行“检查脚本更新”。

### 面板完全消失时的恢复安装

如果网页右下角连“合规连续学习”面板都没有，或旧版回退后仍然没有面板，不要继续在原来的 Tampermonkey 编辑标签页里保存。旧编辑页对应的脚本记录可能已经失效，此时回退代码也不会重新建立脚本记录。

1. 在 Tampermonkey 管理面板中先停用所有辽宁干部学习网相关旧脚本；不必删除。
2. 在 Tampermonkey 管理面板中删除或停用本项目失效的旧记录，然后重新点击 **[点此一键安装脚本](https://raw.githubusercontent.com/bxy1112-sketch/lngbzx-auto-next/main/lngbzx-auto-next.user.js)**。
3. 在新出现的安装确认页点击“安装”；新记录名称应为“辽宁干部在线学习网：合规连续学习（恢复版）”。恢复版使用独立存储，不会继承其他旧脚本中残留的标签页所有者。
4. 只启用这条新记录，然后关闭所有本站旧学习标签页。
5. 重新打开精确入口 `https://zyjs.lngbzx.gov.cn/pc/index.html#/study_center/my_course`，刷新一次；右下角应立即出现面板。

如果面板仍未出现，先不要点击课程。请截取 Tampermonkey 管理面板中这条新记录的“已启用”状态和网页控制台第一条红色错误，以便区分“没有注入”和“注入后报错”。

## 使用方法

1. 登录网站并打开：
   `https://zyjs.lngbzx.gov.cn/pc/index.html#/study_center/my_course`
2. 确认当前栏目为“我的课程”，列表标题为“未完成课程”。
3. 点击网页右下角“合规连续学习”面板里的“开始连续学习”。
4. 脚本会点击当前页第一门已选课程中唯一、可见、文字精确为“开始学习”的按钮。本站可能把播放器打开到名为 `self` 的新标签页；请允许本站打开标签页，并保留自动打开的学习标签页。
5. 新学习标签页只有在能确认它由本次课程列表页打开、仍处于限定启动时间内、课程 ID 有效，并且页面唯一可见课程标题与列表标题一致时，才接管本次队列。随后脚本只处理唯一且明确的“是否继续学习？”确认框，将唯一可见的课程视频静音，再尝试播放，因此不会干扰其他标签页的声音。
6. 每段视频真实结束后，脚本会先确认平台自身是否已经切到下一节；仍未换节时，约 0.35 秒后只点击唯一且语义明确的下一节控件一次，再核验页面确实发生变化，并快速重新检测、自动尝试播放新视频。平台已经换节、控件不唯一或涉及测验时不会点击。
7. 最后一段结束且找不到下一节时，脚本会打开当前课程详情核验 100%；核验通过后返回列表并启动下一门。
8. 当前页课程处理完后，如果分页“下一页”可用，脚本会安全地切到下一页继续。
9. 所有可安全识别的已选课程处理完后，脚本还会要求页面同时明确显示“共 0 门课程”和唯一可见的“暂无课程信息”，并稳定保持一段时间，面板才显示“当前未完成课程列表已处理完”。

建议除本站自动打开的学习标签页外，不要另开课程页面。脚本为每个页面生成独立所有者；普通的其他标签页不会接管、点击或播放当前队列，只有由本次列表页打开并通过课程 ID、来源和可见标题校验的新学习页可做一次限时交接。脚本不会因为等待时间变长就让另一个标签页强行抢占。整页刷新或关闭活动学习页会停止本次队列，刷新后需要回到“我的课程”重新点“开始连续学习”。

## 面板按钮

- “开始连续学习 / 停止连续学习”：启动或立即停止本次队列。停止会取消尚未执行的下一节重试和待播放操作。
- “课程内推进：开启 / 暂停”：临时暂停或恢复当前队列的自动推进，不清除队列记录。
- “重新检测”：页面或播放器加载较慢时，手动触发一次安全扫描。

## 会自动停止的情况

以下情况不会猜测操作，队列会转为停止状态：

- 未能唯一识别课程卡或“开始学习”入口。
- 当前路由的课程 ID 或唯一可见课程标题与列表中绑定的课程不一致。
- 页面出现多个可见视频，无法唯一确定主播放器。
- “是否继续学习”弹窗含测验、考试、答题、练习等语义，或点击后未在限定时间内消失。
- 课程详情没有在限定时间内明确显示 100%。
- 课程列表、详情、播放器、分页或路由未在限定时间内完成加载。
- 本站课程学习标签页被浏览器拦截，或新标签页无法证明来自本次课程启动。
- 课程使用章节选择弹窗、SCORM、测验或其他非普通视频流程。

发生停止后，脚本不会自动恢复点击。处理页面问题后，回到“我的课程”重新点击“开始连续学习”。

如果浏览器阻止自动播放，面板会提示手动点击一次播放器；队列会保持等待，视频正常开始并播放到结尾后可继续运行。

网页重绘或替换页面主体后，恢复版会在下一轮安全扫描时把右下角面板重新挂回当前页面。

## 当前支持范围

- 支持“我的课程 → 未完成课程”中的已选普通视频课程。
- 支持站内 `#/video_detail` 和 `#/video_play` 播放路由。
- 当前站点播放器若在视频结束后自行切节，脚本只确认切换并继续播放；平台未切换时，才点击唯一的白名单“下一节”控件一次，且永不点击右侧课程目录。
- 支持同源 iframe 中的课程视频。
- 支持列表分页。
- 不自动处理章节选择、考试、测验、作业、选课或取消选课。
- 不会对服务器限制、登录状态或进度记账规则做规避；最终进度以平台页面和服务端为准。

站点更新页面结构后，脚本可能保守停止。此时不要改用绕过式脚本，可提供停止状态文字和页面截图以便更新安全选择器。
